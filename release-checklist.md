# Release checklist

- [ ] Confirm all code and included materials may be publicly shared.
- [ ] Add author and maintainer details.
- [ ] Add software dependencies and exact run commands.
- [ ] Select and add an approved license.
- [ ] Validate that main analyses run from a clean environment.
- [ ] Create the GitHub release tag `v1.0.0`.
- [ ] Enable the repository in Zenodo and verify the version DOI.
- [ ] Add the Zenodo DOI to `README.md` and the manuscript's Code Availability statement.
