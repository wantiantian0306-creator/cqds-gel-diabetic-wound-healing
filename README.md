# CQDs@Gel for diabetic wound healing

This repository is intended to host code and analysis workflows for the study:

> Wang T, Yang Z, Yang Y, Wei Z, Zhang L, Li Y, Li F. *A prunetin-derived carbon quantum dots-loaded hydrogel for the treatment of diabetic cutaneous ulcer via reactive oxygen species scavenging.* Colloids and Surfaces A: Physicochemical and Engineering Aspects. 2026;749:141205. https://doi.org/10.1016/j.colsurfa.2026.141205

## Repository structure

- `src/` - analysis and figure-generation scripts
- `data/` - data dictionaries and instructions for obtaining data; do not upload identifiable or restricted data
- `results/` - generated, non-source results where appropriate
- `docs/` - analysis workflow and software environment notes

## Reproducibility

Before public release, add:

1. A dependency file, such as `requirements.txt`, `environment.yml`, or `renv.lock`.
2. A documented entry point and commands needed to reproduce each main figure/table.
3. Metadata, variable definitions, and data-access instructions.
4. A license approved by all rights holders.
5. A tagged release, such as `v1.0.0`, for Zenodo DOI archiving.
